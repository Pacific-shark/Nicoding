## 拆分与先修原则

- “Attention 与 Transformer”“PPO 与 SAC”“VAE、GAN 与扩散”等入口需要拆成连续子单元，保留原节点 URL 作为主题入口。
- 数学在使用前提供必要台阶；兴趣探索可直接进入，提示具体先修，不以点亮状态强制锁门。
- 每个应用单元包含机制解释、可操作实验、边界/失败案例、参考结果和一个新变式。文字、静态图、过程回放和实际代码按知识特点组合。
- 样板 A 已实现；样板 B（指标与阈值）、C（计算图与训练）按发展计划继续详细设计，尚未实现。
