# 知识学习改造：第一批交付

状态：2026-09-10，首个完整知识单元已实现。本文件记录实际范围，不代表发展计划全部完成。

## 课程与体验

- 原 `py-references` 路径升级为“引用、复制与共享状态”，六个相互衔接的章节：名字与对象、浅拷贝与深拷贝、默认参数、修复、解释与迁移、实际配置任务。
- 引用图和代码同屏，支持单步、回退、重置、复制方式切换及等价表格；限定预设例子的范围，并逐步与真实 Python 核对。
- 默认参数实验支持多次调用和两种方案对照；真实代码练习接入既有 Python 运行器。
- 两组各四项行为检查，覆盖意外共享、显式空列表、选择性复制、重复标签和多次派生。提示、参考实现、错误原因与完整错误位置分别呈现。
- 单元位置、实验、代码、结果和解释随本机进度保存及备份；结果绑定代码快照，过期结果不能作为当前代码的验收证据。
- 导航和字体统一，各方向的强调色采用杏色、鼠尾草绿、陶土橙、灰紫等轻量变化。现有优先节点效果保留。
- 本单元中的 Nico 默认靠在桌面章节侧栏，手机上收为小标签；仍可展开、拖动和使用原有助手功能。

## 教学范围

先修为函数与容器。本单元针对 Python 内置列表、字典和明确约定的输入；没有实现通用 Python 调试器。图中的对象编号不是内存地址。

解释采用具体问题、反例和自查要点，不按字数评分，不自动判断自然语言解释正确。行为检查验证题目契约，不认证通用工程能力或排除外部 AI 帮助。

## 设计实现约定

采用已生成的引用课程全屏概念作为布局参考：章节侧栏、开放式主标题、讲解与代码/对象图同屏、预测反馈以及连续章节导航。沿用当前站点的品牌、导航和小猫资产；概念图中的简化猫、导航高亮错误和搜索占位文案不进入实现。

新增的表格替代视图、先修资料和后续练习属于课程完整性与可访问性的必要内容，使用同一套配色、文字与控件。较窄桌面和手机按顺序堆叠图、代码、结果，章节侧栏在手机上变为选择框。
