# Nicoding：章节课题与知识星图

2026-09-18。主目录改为领域章节 → 多个课题 → 有交付物的步骤。知识点独立维护，课题步骤通过 ID 引用；知识页反向列出使用它的课题。旧进度、实验、Nico v8 资产保留。

## 页面约定

- 课程：固定 72px 顶栏、218px 章节栏、开放式课题路线。每个课题显示难度、运行地点、来源与产出。
- 星图：按领域聚类；总览仅显示代表节点，选择领域展开全部；边只表示实际先修，选择节点强调一跳依赖；搜索、缩放、拖动、复位、键盘选择、列表模式。
- 知识：独立地址，目录、专业正文、公式与算例、交互或真实代码实验、理解检查、先修和反向课题链接。
- 课题：固定步骤栏，任务、源码定位、知识旁栏、验收清单、实验记录。自报进度与自动验证分开，不把勾选称为通过测试。

## 内容与研究约定

GitHub 来源固定到核对过的提交，链接到具体文件。课程讲解和任务为原创，不搬运书籍正文。复现分清算法机制、小规模教学实验和完整论文结果；每个本地课题说明范围、依赖、数据、资源和证据。浏览器不假装执行 PyTorch/GPU。既有 Bank 真实实验仍可运行。

新课题记录与知识记录纳入已有备份，兼容旧版。阅读、检查答案、运行代码与自报交付分开记录。
