# Nicoding 1.0 验收记录

2026-09-08，本地 Chrome + Playwright，Node 24.19.0 / Pyodide 0.27.7（Python 3.12.7）。

## 内容

60 个节点，141 道理解题，15 组代码挑战，51 个独立行为/边界断言，46 个不同资料入口，5 个迁移项目。

课程 ID 唯一、先修关系存在且无环、测验选项与解释对应、资料链接格式有效。所有示例通过本地语言运行检查，所有参考解法通过断言，所有错误起始代码至少触发一个失败。

在实际浏览器工作线程执行全部 60 个示例、15 个参考解法与 15 个错误起始程序。首次发现 SQL 示例缺少 Pyodide 的 unvendored sqlite3 模块；已打包官方固定版本 wheel、核对 SHA256 并复测 `import sqlite3` 与 `from sqlite3 import connect`，都得到真实查询结果。其余浏览器代码检查通过。

SQLite wheel SHA256：`43061928762b03482676a1e11dcef99a003148e59fe914b6a3e41180c382cfc3`。

## 功能路径

- 领域筛选、只看优先、无结果状态、空间/平面切换、拖动、缩放、重置视角。
- 搜索快捷键、无搜索结果、跳转课程与先修节点。
- 错误代码被拦住、正确代码通过、代码改动使当前验证失效。
- 测验错误解释、答案修改使当前通过状态失效、完成条件检查、辅助记录。
- 笔记保存、代码挑战草稿跨步骤保留、刷新恢复。
- 自动复习安排与提前复习，正确作答后保存复习次数。
- 项目清单和复盘自动保存。
- JSON 导出；无效导入不替换记录；有效导入先展示摘要，再确认恢复。
- Nico 点击菜单、打盹、拖动、点亮回应、关闭动效；编辑器聚焦时避让。
- 无限循环约 5 秒后终止，随后能启动新工作线程执行正确代码。
- 桌面与手机浏览器没有页面脚本错误；核心学习运行不请求外部 CDN。

## 视觉与可用性

对照已确认的主界面和学习页概念图，逐项检查：

1. 保留 Nicoding 衬线字标和猫耳轮廓，改为深棕/焦糖色。
2. 采用象牙白底、杏色镜面节点、低饱和琥珀点缀，避免暗色颗粒背景。
3. 桌面保留“领域导航 / 大幅知识树 / 课程详情”的三栏层级，删除大标题“工程基础”。
4. 优先动效只出现在节点环上；连线静止，并按真实先修关系绘制。概览简化中间节点，实线与虚线有图例。
5. 学习页把步骤、编辑器/结果与辅助讲解分开；代码有轻量语法着色，文字区保持稳定。
6. 使用同一只金加白短腿 Nico 的六姿态图，实际素材已复制进应用目录。
7. 窗口宽度 1280、1024、768、390、360 下检查页面无横向溢出；窄屏详情变为可收起面板，主导航放在底部。
8. 尊重系统减少动效偏好，并提供应用内动效开关；对话框可以键盘退出，主要操作有可见焦点。

相对概念图的功能性调整：起始建议按真实先修顺序从变量开始；进度不预填；“加入复习”改为完成后自动安排；节点点亮需要实际检查；长课程允许自然滚动；完整深度训练明确指向外部教程和计算环境。
